# G minor 6th arpeggios

All Gm6 arpeggio positions on the fretboard, standard tuning, frets 0-16. Gm6 = `1 b3 5 6` = **G Bb D E**.

The folder name is the root note: `minor/G` holds G minor arpeggios.

How these were made: every four-fret window from fret 0 to fret 16 (nothing above fret 16) that contains all four chord tones, played in pitch order across the strings. Windows whose notes are wholly contained in another window were dropped. Every fret was checked against G, Bb, D, E.

## Two notes per string

Two chord tones on each string, rising through consecutive chord tones (G Bb D E G Bb ...), on three to six adjacent strings, up to fret 16. Every pair of neighbouring strings fits one hand position (four notes within six frets); longer shapes shift position as they climb, which is marked in the file. Shapes that are part of a longer shape are not listed separately. Every fret checked against G, Bb, D, E, and every shape contains all four chord tones.
