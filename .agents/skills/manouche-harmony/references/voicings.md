# Voicings

Fret strings run **low E → high e**, one character per string, `x` = muted. `n` = the fret of the root note.

Every shape below was checked note by note. The tone column lists the chord tones from the lowest sounding string upward.

## Movable: root on the 6th string (low E)

| Quality | Frets | Tones | Example (root note) |
| --- | --- | --- | --- |
| 6/9 | `n x n-1 n+1 n n+2` | 1 6 3 5 9 | `3x2435` = G6/9 |
| 6 | `n x n-1 n+1 n x` | 1 6 3 5 | `3x243x` = G6 |
| m6 | `n x n-1 n n x` | 1 6 b3 5 | `3x233x` = Gm6 |
| 7 | `n n+2 n n+1 n n` | 1 5 b7 3 5 1 | `353433` = G7 |
| 7 (shell) | `n x n n+1 n x` | 1 b7 3 5 | `3x343x` = G7 |
| 9 | `n n+2 n n+1 n n+2` | 1 5 b7 3 5 9 | `020102` = E9 |
| 13 | `n x n n+1 n+2 x` | 1 b7 3 13 | `3x345x` = G13 |
| dim7 | `n x n-1 n n-1 x` | 1 6 b3 b5 | `3x232x` = Gdim7 |

The m6 shape is the workhorse of minor-key comping. For A minor it lands at the 5th fret: `5x455x`, which is the same chord as the open `x0455x`.

## Movable: root on the 5th string (A)

| Quality | Frets | Tones | Example (root note) |
| --- | --- | --- | --- |
| 6/9 | `x n n-1 n-1 n n` | 1 3 6 9 5 | `x32233` = C6/9 |
| 6/9 (thin) | `x n n-1 n-1 n x` | 1 3 6 9 | `x3223x` = C6/9 |
| m7b5 | `x n n+1 n n+1 x` | 1 b5 b7 b3 | `x3434x` = Cm7b5 |
| 7 (shell) | `x n n-1 n x x` | 1 3 b7 | `x323xx` = C7 |
| 9 | `x n n-1 n n x` | 1 3 b7 9 | `x3233x` = C9 |
| 13 | `x n n-1 n n+2 x` | 1 3 b7 13 | `x3235x` = C13 |
| m7 | `x n n+2 n n+1 x` | 1 5 b7 b3 | `x3534x` = Cm7 |
| dim7 | `x n n+1 n-1 n+1 x` | 1 b5 6 b3 | `x3424x` = Cdim7 |
| maj7 | `x n n-1 n-3 n-3 n-3` | 1 3 5 7 3 | `x32000` = Cmaj7 |

Notes
- The maj7 shape only sits comfortably in low positions; that is one reason maj7 is not the default major color in this style.
- The A-string m6 shape exists but wraps awkwardly above the open position. Use the low-E m6 shape instead, or the open `x0455x`.
- The 6/9 shape is the one to practice to death. It covers most major chords in the repertoire.

## Voice-leading practice

Take `Cmaj6/9 → Am6 → Dm6 → G13 → Cmaj6/9` and find the closest possible voicings, one per bar. Write down the top note of each chord. If the top line looks like a melody, the comping will sound like music.

Another useful loop: `C6/9 → C#dim7 → Dm7 → G13`. Keep the top voice moving down by half steps. Dim7 chords are the easiest place to hear voice leading, because every note is a half step from the next chord tone.
